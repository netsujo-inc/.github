### Agent Role Contracts

**Check AI-agent roles, authority, task scope, review separation, and handoffs before execution.**

Agent Role Contracts is an open-source, offline checker for declarations used in AI-agent workflows.

A passing check means the supplied declarations are internally consistent. It does **not** authorize execution, enforce runtime permissions, authenticate identities, or prove that an action actually occurred.

- [Source & quickstart](https://github.com/suirindo/agent-role-contracts)
- [npm package](https://www.npmjs.com/package/@netsujo/agent-role-contracts)
- [Issues](https://github.com/suirindo/agent-role-contracts/issues)

### Netsujo AIO/SEO Skills

**Practical AIO/SEO skills for Next.js, Strapi, and Japanese-language websites.**

A Claude Code toolkit developed through work on Netsujo's own websites, covering areas such as structured data, search visibility, content validation, indexation, and measurement.

Some skills require external services or credentials. The project does not guarantee search rankings, AI citations, or business outcomes.

- [Source & setup](https://github.com/suirindo/netsujo-aio-seo)
- [Issues](https://github.com/suirindo/netsujo-aio-seo/issues)
